================================================================================
                            API ENDPOINTS
================================================================================

POST /submit-feedback
├─ Authentication: Required (user must be logged in)
├─ Parameters:
│  ├─ type: "helpful" | "not-helpful" | "neutral"
│  ├─ advice_text: String (the advice being rated)
│  └─ detailed_comment: Optional string
├─ Response: { "success": true, "message": "..." }
└─ Error Codes: 401 (not logged in), 400 (invalid data)

GET /feedback-stats
├─ Authentication: Required (admin only)
├─ Response: {
│  "success": true,
│  "stats": {
│    "total": number,
│    "helpful": number,
│    "not_helpful": number,
│    "neutral": number
│  }
│}
└─ Error Codes: 401 (not logged in), 403 (not admin)

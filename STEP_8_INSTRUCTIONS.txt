================================================================================
  TROUBLESHOOTING
================================================================================

ISSUE: Still seeing "Firebase not initialized"
  Cause: Credentials file not found or invalid
  Solution:
    1. Check file exists: dir firebase_credentials.json
    2. Check file is valid JSON
    3. Check file location is correct
    4. Restart app

ISSUE: "Permission denied" error
  Cause: File permissions issue
  Solution:
    1. Right-click file → Properties
    2. Check "Read" permission enabled
    3. Restart app

ISSUE: "Invalid credentials" error
  Cause: Corrupted or invalid credentials
  Solution:
    1. Download new credentials from Firebase Console
    2. Replace the file
    3. Restart app

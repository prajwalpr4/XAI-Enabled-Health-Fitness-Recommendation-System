================================================================================
  ARCHITECTURE
================================================================================

DUAL STORAGE MODE:

User Request
    ↓
Firebase Initialized?
    ├─ YES → Firebase Cloud Storage
    │   ├─ Firebase Auth
    │   ├─ Realtime Database
    │   └─ Real-time Sync
    │
    └─ NO → Local JSON Storage
        ├─ Local Authentication
        ├─ JSON Files
        └─ File-based Storage

================================================================================
  DATABASE STRUCTURE
================================================================================

Firebase Realtime Database:

users/
├── {uid}/
│   ├── email: string
│   ├── name: string
│   ├── created_at: timestamp
│   ├── profile/
│   │   ├── age, weight, height
│   │   ├── bmi, bmr, tdee
│   │   └── fitness_goals
│   ├── feedback/
│   │   └── {feedback_id}/
│   │       ├── type, text, comment
│   │       └── timestamp
│   ├── tracking/
│   │   └── {tracking_id}/
│   │       ├── calories, exercise
│   │       └── timestamp
│   └── recommendations/
│       └── {rec_id}/
│           ├── type, content
│           └── timestamp

  TROUBLESHOOTING
================================================================================

FIREBASE NOT INITIALIZING:

→ Verify JSON file is valid
→ Check Firebase project is active
→ Verify database URL in credentials

AUTHENTICATION ERRORS:

→ Check email spelling
→ Verify password is correct
→ Check Firebase Auth is enabled

DATA NOT STORING:
→ Check database exists
→ Verify security rules allow write
→ Check user is authenticated
→ Review application logs
